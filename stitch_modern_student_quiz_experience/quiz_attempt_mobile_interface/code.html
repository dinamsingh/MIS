Consider the following Python implementation of a graph traversal algorithm...

Which traversal strategy does this code snippet best represent, assuming `stack` behaves strictly as Last-In-First-Out? 

def traverse(graph, start):
    visited = set()
    stack = [start]
    while stack:
        vertex = stack.pop()
        if vertex not in visited:
            visited.add(vertex)
            stack.extend(graph[vertex] - visited)
    return visited
